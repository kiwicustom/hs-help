How to join

An operator invites you from the admin users page. There is no public signup.

  1. 1

    Wait for the Alles Hockey invite email (code + link).

  2. 2

    Optional: install the Android app first (recommended on phone).

  3. 3

    In the website or app: enter email + mail code → Continue.

  4. 4

    Create your PIN (step 2). That is how you sign in after logout.

Open the mail link only inside the same browser/app you want logged in. Prefer entering the code in the app.
